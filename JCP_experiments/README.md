# JCP_experiments — LSC-CP compound-Poisson sampling benchmark

Standalone experiment tree for the JCP submission on **LSC-CP**
(Lévy-Score-Corrected Compound Poisson): overdamped Langevin dynamics plus
finite-activity nonlocal jumps plus the stationary Lévy-score drift
correction that preserves the Boltzmann target exactly at the generator
level. Raw CP (same jumps, no correction) is the key ablation; five local /
tempering baselines complete the comparison.

## Quick start

```bash
conda activate jcp-exp                      # torch 2.13 + cu130, fp64
cd JCP_experiments
JCP_GPU=4 python -m pytest tests -q         # 22 tests, ~30 s (needs 1 GPU)

cd notebooks
python build_notebooks.py                   # regenerate the four notebooks
JCP_GPU=4 jupyter nbconvert --to notebook --execute --inplace 01_double_well.ipynb
# ... same for 02_mog40, 03_muller_brown_10d, 04_coupled_phi4
```

**GPU policy:** GPUs 0–3 belong to another project and are forbidden.
`src/gpu_guard.select_gpu` must run before `torch` is imported; it masks
`CUDA_VISIBLE_DEVICES` to exactly one of {4,5,6,7} (`JCP_GPU`, default 4).

## Layout

```
src/
  gpu_guard.py     GPU masking (import before torch)
  config.py        beta=8, eps=0.125, lambda=1, seeds, RNG scheme
  potentials.py    E1 double well, E2 MoG40, E3 transformed Mueller-Brown 10D,
                   E4 coupled phi4 chain (+ moment-exact homogeneous V_delta)
  jumps.py         shell / annulus jump laws + Poisson jump application
  score.py         Levy score: log-space (M, v) accumulation, MoG40 closed
                   form with branched log-bracket, brute-force validators
  samplers.py      ULA, MALA, FLA, BAOAB, PT, raw CP, LSC-CP (shared taming)
  metrics.py       W2 (exact/sliced/Hungarian), TV, MMD, EMC, EJS, bias floors
  certificate.py   weak stationarity residual R(phi): log-space grid form
                   (E1-E3) + shifted-form importance sampling (E4)
  references.py    reference samplers + gradient-flow basin maps
  experiments.py   experiment builders (single source of truth for tests
                   and notebooks)
  runner.py        checkpoint loop, defensible timing, CSV/manifest emission,
                   quadrature + dt refinement, ULA first-passage verification
  plotting.py      manuscript figures (EPS-safe: no alpha anywhere)
notebooks/         01-04 (generated by build_notebooks.py), self-contained
tests/             score/certificate/sampler/metric validation (run first)
results/           CSVs + manifests (gitignored)
figures/           pdf/png/eps + caption txt (gitignored)
```

## Protocol invariants (enforced in code/tests)

* float64 everywhere; no `.item()`/`.cpu()`/host sync inside sampler steps.
* One taming map for every method's drift; tamed MALA stays exact.
* The nu used by the score quadrature and the nu used to draw jumps are the
  same measure (tested); raw CP and LSC-CP share a pathwise-identical jump
  stream (tested).
* Timing covers sampler work only, cuda-synchronized, 20 untimed warm-up
  steps, seeds sequential; PT wall-clock includes all replicas.
* Certificate R(phi) < 1e-6 on a domain extending a full jump length beyond
  the target's support (a deliberately tight box fails, regression-tested);
  drift integrand assembled in log space.
* Production is gated on: tests green, certificate, quadrature refinement
  table, dt refinement rule (5% dyadic), ULA first-passage vs Kramers.
