The canonical commands are recorded in \texttt{STATUS.md}. A full run consists of unit tests, smoke tests, bounded core-suite launches with \texttt{--gpus 0,1 --max-concurrent 2}, manifest-scoped aggregation, figure generation, report asset generation, and compilation with \texttt{tectonic}. The old ICLR outputs are not used as output targets.
